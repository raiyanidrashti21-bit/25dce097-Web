StudentHub Portal

Project Overview
StudentHub is a student portal developed using HTML, CSS, JavaScript, PHP, and MySQL.

Technologies Used
* HTML5, CSS3, JavaScript
* PHP and MySQL
* XAMPP

Main Features
* Responsive pages built with semantic HTML5, CSS3 and JavaScript
* Registration form with frontend (JavaScript) and server-side (PHP) validation
* Secure registration with MySQL, duplicate email check and password hashing
* Secure login/logout with PHP sessions, role-based access and session timeout

Installation and Execution
1. Install and start Apache and MySQL using XAMPP.
2. Copy the StudentWebsite folder into htdocs.
3. Import the exported SQL database through phpMyAdmin.
4. Open http://localhost/StudentWebsite/ in a browser.

Testing
The project was tested by opening the website locally and checking registration, login, logout, session timeout and access control.

Conclusion
StudentHub demonstrates the use of frontend technologies, PHP and MySQL to develop a secure student portal.
